# ICT Trading Journal
Binance Futures verilerini kullanarak backtest sonuçlarını TradingView tarzında görselleştiren bir web uygulaması.

### Kurulum
1. Repoyu clone'layın.
2. `data/btcusdt.json` dosyasını kendi verilerinizle güncelleyin.
3. `index.html` dosyasını herhangi bir modern tarayıcıda açın.

### Özellikler
- Binance Futures 1m verileriyle otomatik senkronizasyon.
- Long/Short pozisyon kutuları (TV Style).
- Günlük bazda gruplanmış not defteri görünümü.
